Como usar o sistema?

  1. Faça login com seu e-mail e senha.
  2. Acesse o Catálogo para pesquisar livros por título, autor ou categoria.
  3. Confira o selo de disponibilidade em cada livro.
  4. Use Cadastrar livro para adicionar títulos ao acervo.
  5. Cadastre alunos antes de registrar empréstimos.
