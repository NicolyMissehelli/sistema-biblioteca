# Backend — Novaris Tech Biblioteca

## Tecnologia
- Node.js
- Express
- CORS

## Instalação

Dentro desta pasta:

```bash
npm install
```

## Executar

```bash
npm start
```

A API ficará disponível em:

http://localhost:3000

## Principais endpoints

POST /api/login
GET /api/livros
POST /api/livros
GET /api/alunos
POST /api/alunos
GET /api/emprestimos
POST /api/emprestimos
GET /api/dashboard

## Observação
Este backend usa dados em memória apenas para demonstração.
O próximo passo é substituir os arrays por um banco de dados, como MySQL.
